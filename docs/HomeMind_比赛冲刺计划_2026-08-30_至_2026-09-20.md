# HomeMind 比赛冲刺计划（2026-08-30 至 2026-09-20）

> 目标：在 2026-09-20 前，以 ESP32-S3-EYE + OpenVela/ai_agent 为唯一主线，完成与初始报名方案一致、可复现、可真机演示的最小完整作品，并按官方要求提交。
>
> 冻结项：不使用 ESPHome；不制作外壳；不新增自制 PCB；不扩展与评分无关的功能。

## 1. 最终作品定义

HomeMind 最终演示不是“五个独立 Demo”，而是一条完整故事线：

1. ESP32-S3-EYE 运行 OpenVela/ai_agent，冷启动后自动联网；
2. 板载麦克风检测统一唤醒词“你好，openvela”，断网时也能完成唤醒反馈；
3. 板载摄像头在端侧完成一种真实轻量感知：人员/人脸存在检测；
4. 感知事件或自然语言文本进入家庭私有服务，由 MiMo 生成受 JSON Schema 约束的任务；
5. 任务通过 MQTT/家庭网关下发，控制一台真实米家设备，并产生 ack/done/status；
6. 小程序展示设备、感知事件、待办/日程与执行结果；
7. 断网情况下，统一唤醒词和一个基础本地命令仍可控制板载 LED/LCD；
8. 原始音频和摄像头画面不上传公网，只允许经用户确认的文本请求发送给 MiMo。

不把以下内容列为最终承诺：身份识别、完整手势库、连续语音助手、扬声器播报、多房间部署、多台米家设备、自制 PCB/外壳。

## 2. 四项原始承诺的最小交付边界

| 原始承诺 | 比赛版最小真实实现 | 完成定义（Definition of Done） |
| --- | --- | --- |
| 离线唤醒与端侧感知 | 统一唤醒词 + 人员/人脸存在检测；LED/LCD 反馈 | 断开外网仍可唤醒；摄像头实时帧参与推理；连续 20 次测试统计成功率和延迟；无测试图、固定值或音量阈值冒充 |
| 端云语义与任务转化 | 文本/本地转写结果 → 家庭服务 → MiMo → JSON 任务 → MQTT | 至少 3 类自然语言表达稳定生成白名单 JSON；非法字段被拒绝；设备返回 ack/done/status；原始音视频不发往 MiMo |
| 米家与小程序互联 | 1 台真实米家灯/插座 + 小程序设备/事件/日程/资产页 | 真机开关各 10 次；小程序实时显示结果；SQLite 中至少有真实任务、事件、资产数据；不显示虚构温湿度 |
| 隐私与离线闭环 | TLS、凭据不入库、音视频留在局域网、本地基础控制 | 仓库与日志秘密扫描通过；断公网演示唤醒和 LED/LCD 本地控制；文档如实说明“文本会发送至 MiMo” |

# 腾讯云操作清单（二）：米家实体自动同步后端部署 — 交 workbuddy 执行

背景：家庭网关已在 status 消息里上报米家实体快照 `mihome_entities: [{entity_id, name, state}]`（名称如"阳台开关"，2026-09-06 已在网关侧实测）。云端 API 需要部署 5 个后端文件，把快照存库并下发给小程序，设备页即可自动显示实体名称，不再手填 entity_id。

## 变更文件（共 5 个，全部在仓库 `backend/api/app/` 下）

| 仓库文件 | 部署到云端 | 变更内容 |
| --- | --- | --- |
| `app/models.py` | 同路径 | `DeviceStatus` 新增 `mihome_entities` TEXT 列 |
| `app/db.py` | 同路径 | 新增 `ensure_sqlite_columns()` 轻量迁移（ALTER TABLE 补列） |
| `app/main.py` | 同路径 | 启动时 `create_all` 后调用迁移 |
| `app/mqtt_client.py` | 同路径 | status 消息存实体快照 + WSS 透传 |
| `app/routers/devices.py` | 同路径 | `GET /v1/devices` 返回 `mihome_entities` |

## 操作步骤

```bash
ssh <腾讯云主机>
cd <backend 部署目录>

# 0) 备份数据库（迁移只加列，不动数据，但按惯例先备份）
cp api/data/homemind.db api/data/homemind.db.bak.$(date +%Y%m%d_%H%M%S)

# 1) 用仓库对应文件覆盖云端同路径文件（5 个）
#    <repo>/backend/api/app/models.py        -> ./api/app/models.py
#    <repo>/backend/api/app/db.py            -> ./api/app/db.py
#    <repo>/backend/api/app/main.py          -> ./api/app/main.py
#    <repo>/backend/api/app/mqtt_client.py   -> ./api/app/mqtt_client.py
#    <repo>/backend/api/app/routers/devices.py -> ./api/app/routers/devices.py

# 2) 本地语法检查后再构建（可选但建议）
python3 -m py_compile api/app/models.py api/app/db.py api/app/main.py api/app/mqtt_client.py api/app/routers/devices.py

# 3) 重建并只重启 api 容器
docker compose build api
docker compose up -d api
sleep 8 && docker compose ps && docker compose logs api --tail 15
```

## 验收（按顺序）

1. `curl -s https://hfy-ai.cloud/v1/health` → `{"status":"ok",...}`；
2. 触发一次实体快照上报：在家庭 Ubuntu 上执行一条 mihome 命令（或让用户在小程序点一次"查状态"）；网关 done 后会发 status；
3. 数据库确认（任选其一）：
   - `docker compose exec api python -c "import json,os; from sqlalchemy import create_engine, text; e=create_engine('sqlite:////app/data/homemind.db'); print(list(e.connect().execute(text('select device_id, mihome_entities from device_status'))))"` → 应看到 `[{"entity_id": "switch.linp_cn_950233435_t2dbw1_on_p_2_1", "name": "阳台开关", "state": "..."}]`；
   - 或让用户刷新小程序设备页，"米家设备控制"卡片应显示"阳台开关（开/关）"实体行，不再要求手填实体 ID；
4. 旧记录兼容：`device_status` 已有行通过 ALTER TABLE 补列，`mihome_entities` 初始为空串 → API 返回空列表 → 小程序走手动兜底 UI，直到下一次 status 上报刷新。

## 红线（同第一份清单）

- 不修改 `.env`（WX_APPSECRET/JWT_SECRET/MQTT_PASS），不重生成 mosquitto 密码；
- 不动 nginx/mqtt 容器；不新增公网端口；
- 若 `docker compose build api` 失败，回滚 5 个文件为部署前内容并重新 build/up，回报错误输出。

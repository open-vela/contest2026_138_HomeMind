## 2 摘要（≤300 字，已按 09-12 事实改写）

HomeMind 面向家庭场景，在 ESP32-S3-EYE 上运行 OpenVela（Apache NuttX）与官方 `ai_agent`，形成「端侧感知与执行 + 家庭局域网服务 + MiMo 云智能」的协同中枢。本轮已验收：冷启动联网与 TLS 调用 MiMo 非固定问答；白名单本地工具（LED、设备信息）；LCD 三态显示与 /data 凭据持久化；运行时 Skill 列表可读；家庭 FastAPI/SQLite/Mosquitto/网关/HA 链路下，板载 LED 开/关各 10/10，多功能房吸顶灯开/关各 10/10 且 HA 回读 20/20 一致。端侧另有实验性混合存在检测、连续 PCM 与能量 VAD。指定词 KWS「你好，openvela」未达可用；严格私有化与完整睡前语义任务未实现，报告如实披露数据外发边界。

## 3.1 绪论（要点）

- 背景：家庭设备入口碎片化；语音/视觉与本地控制割裂；公有云直连隐私顾虑。
- 问题：在资源受限 MCU 板上，如何稳定完成「感知—理解—本地执行—真实家电回读」，并让评委可复现。
- 难点：OpenVela 端侧工具调用与异步 Agent；串口网关与 MQTT 双连接；HA/米家状态一致性；视觉/音频在 DRAM/栈限制下的可靠性。
- 创新点：板端 `ai_agent` 工具白名单 + 家庭网关把自然语言落到真实灯并强制回读确认；运行时 Skill 平铺加载；端云职责可按断网降级。

## 3.2 系统方案（要点）

```text
[小程序/开发者工具] --HTTPS/WSS--> [入口 API]
        |                              |
        |                         (可选 relay 出站)
        v                              v
[家庭 FastAPI+SQLite] <--MQTT--> [家庭网关] --串口--> [ESP32-S3-EYE ai_agent]
        |                              |
        +-------- MQTT 本地/云端 -------+
                                       |
                                 [HA] --> [米家吸顶灯]
板端另可：MiMo HTTPS 工具/问答；实验性 vision/audio 命令
```

- 端：OpenVela/ai_agent、工具注册表、LCD/LED、媒体采集命令。
- 家庭：认证 MQTT、JWT、命令 TTL/防重放、HA 适配与白名单实体。
- 云：MiMo；公网入口仅作可达性/登录，业务正文优先落家庭 SQLite（严格隐私未验收）。
- 断网：板端 agent_loop 依赖 Wi-Fi 起来后启动；无网时 ask 排队（已知边界）。

## 3.3 算理与 openvela 能力

- 云端：大赛 MiMo（HTTPS，Token 不入仓）。
- 端侧实验：混合存在检测（肤色+边缘+运动+TFLM 分数）；**非**通用人体检测；约 4.16s/帧量级（历史记录）。
- 音频：I2S 连续 PCM；能量 VAD；**非**指定词 KWS。
- openvela 落地能力：**AI**（ai_agent/工具/Skill）+ **多媒体**（摄像头/I2S/LCD）；图形用 LCD 状态显示。
- 本地快速路径：「打开灯/关灯」→ `led_control` → `{"led":"on"|"off"}`；网关必须等到 `[Agent]:` 才 done。

## 3.4 实现（要点）

- 固件 overlay：`firmware/ai_agent_overlay/`；部署 `tools/deploy-to-vm.sh`；产物 `artifacts/` + `SOURCE_SNAPSHOT.json`。
- 网关：`backend/gateway-agent/gateway_agent.py` 双 MQTT（`LOCAL_MQTT_*`）；`CMD_MODE=ask`；异步 `[Agent]` 等待修复。
- API：`backend/api/app`，`ALLOWED_ACTIONS` 含 `mihome.set_power/get_state`；`relay_proxy` 已修 await/状态码。
- 运行时 Skill 路径：`/data/ai_agent/skills/`（与模板示例 `/data/agent/skills/` 不同，按实际 loader）。
- 开发 Skill：`skills/homemind-build-flash-accept/SKILL.md`（构建—烧录—验收—归档）。
- 自定义运行时 Skill：仓内 `app/homemind/skills/home_security.md` 等 5 个；真机可 `技能列表` 列出当前 /data 下技能。

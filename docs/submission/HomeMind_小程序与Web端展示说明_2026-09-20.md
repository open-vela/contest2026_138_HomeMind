## 三、Web 端（家庭侧）：家庭事件实时证据墙

**地址**：`http://192.168.31.251:8099`
**服务**：`homemind-livefeed`（当前 `active`，HTTP 200）
**实现**：`livefeed.py`，服务端渲染，读 SQLite 的 `home_events` 表

**页面内容**（实测）：
- 标题：**HomeMind · 家庭事件实时证据**
- 深色卡片式布局，顶部有 `LIGHT`（灯）与 `SPK`（音箱）两个常驻状态位
- 下方是事件流水：`light_state_changed` / `bedtime_scene_auto` / `light_on_task_auto` 等，带时间戳

**展示要点**：
- 这是**唯一能一屏证明「端 → 私有云 → 真实设备 → 状态回读」闭环**的材料，视频里**强烈建议给它 5~8 秒**。
- 拍法：全屏打开 → 对小爱说「关灯」→ 页面会**当场滚出新事件**（这一下很打动人）。
- 注意：页面时间戳是**服务器 UTC 时间**（比本地早 8 小时），镜头要读时间时别念错。

## 四、小程序：微信小程序（源码完整）

**代码位置**：`miniprogram/`
**页面**：`index`（首页）/ `dashboard`（看板）/ `devices`（设备）/ `calendar`（日程）/ `settings`（设置）
**云端**：`utils/api.js` + `utils/ws.js`，默认 `app.globalData.serverUrl = https://hfy-ai.cloud`

### 4.1 云端现在是活的（实测 2026-09-20）
| 探测 | 结果 | 含义 |
| ---- | ---- | ---- |
| `https://hfy-ai.cloud/v1/health` | **200** | 云端 API 在线 |
| `https://hfy-ai.cloud/v1/devices` | **401** | 接口在线，只是需要登录令牌（鉴权生效） |
| `https://hfy-ai.cloud/docs` | **200** | 提供完整 Swagger 文档 |
| `www.hfy-ai.cloud` | 301→HTTPS 静态页 | 备用域名同样可用 |

也就是说：小程序 **可以真的登录并下发命令**，不是空壳。

### 4.2 已实现的能力（据 `miniprogram/README.md`）
- 微信登录：`POST /v1/auth/wechat/login`
- 设备列表：`GET /v1/devices`
- 下发命令：`POST /v1/devices/{id}/commands`（开灯 / 关灯）
- 命令状态：`GET /v1/commands/{id}`，以及 WSS `/v1/ws/app?token=...` 推送 ACK（心跳 20 s）
- 设备页登录后自动绑定 `esp32s3-eye`；**只有收到最终 `done/expired` 才解除防重入**
- 小程序侧**不持有** AppSecret / 证书私钥 / 设备主密钥 / MiMo Token

### 4.3 怎么演示
1. 装 **微信开发者工具**，打开 `miniprogram/` 目录
2. 在 **详情 → 本地设置** 里勾选 **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**
3. 用**自己的微信**在模拟器里登录
4. 进 **设备页** → 绑定 `esp32s3-eye` → 点 **开灯 / 关灯** → 观察命令状态从 `acked` 走到 `done`

### 4.4 口径红线（README 里明确写了，别越界）
**已知未验收**（README 原文）：
- 「多功能房吸顶灯的小程序**全链路**、**手机真机**、**弱网与权限**仍待验证」
- 日程仅存微信本地 Storage，**未接云端持久化**
- 未接温湿度/光照/噪声传感器，页面统一显示 `--` / `未接入`
- 告警、消息通知、隐私模式开关**尚未接入**

**可以说**：「小程序已具备登录、设备绑定、下发与状态回读的开发链路，云端已在线，可在开发者工具中演示。」
**不要说**：「小程序真机全链路已验收」「小程序已接入传感器 / 已接入告警」。

## 五、展示顺序建议（视频里）

1. **板子屏幕特写**（主线）——证明端侧确实收到并做出可感知反馈
2. **小爱 + 真实灯**（主线）——证明控制的是真设备
3. **家庭证据墙**（5~8 s）——证明私有云端在编排
4. **公网官网 + `/docs`**（5~8 s，可选）——证明有公网云与真接口
5. **小程序开发者工具**（8~12 s，可选）——证明多端可接入

后两项都是**加分项，不是必交材料**（必交只有技术报告 + 演示视频，涉硬件实物加照片）。**优先保证主线**。

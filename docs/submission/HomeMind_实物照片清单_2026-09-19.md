# HomeMind 实物照片拍摄清单（2026-09-19）

> 用途：大赛「作品展示照片」材料（模板列为**可选**；因本项目涉及硬件实物，**建议提交**）。
> 建议命名：`01_前视图.jpg`、`02_后视图.jpg` …… 统一放 `/照片/` 目录，随压缩包一起提交。

---

## 一、拍摄前必须做到（否则重拍）

| # | 事项 | 说明 |
| - | ---- | ---- |
| 1 | **清理画面中的敏感信息** | 屏幕 / 电脑 / 串口终端 / 便利贴上一律**不得**出现：Wi-Fi 密码、`MEDIA_TOKEN`、`.env` 内容、服务器密码、任何 `Bearer xxx`。拍摄前把电脑切到无关页面或合盖。 |
| 2 | **板子已上电且在运行** | LCD 应显示 **「一切就绪」+ 笑脸 + 底部 [灯 开] [助手 就绪]**。**若显示「网络未连接」+ 伤心脸，说明板端 Wi-Fi 掉了**，先按《最终提交操作清单》里的「板子网络修复」处理，否则屏幕会带着错误提示入镜。 |
| 3 | **灯的状态可控** | HA 里 `light.leishi_cn_940744854_eps127_s_2_light` 当前为 `on`。拍「关灯场景」前先确认它是 `on`，这样关灯才能触发睡前模式。 |
| 4 | **桌面干净** | 深色哑光桌面最佳，避免反光桌面和高饱和背景；线材收拢，不要横穿画面。**本项目为裸开发板（无 3D 打印外壳）**，如实拍即可，不必刻意回避排线，但要把线理成一条整齐的走向。 |
| 5 | **光线** | 窗侧自然光 + 一盏台灯补面光，避免顶灯直射造成屏幕反光。**LCD 是镜面，务必避开正上方光源**，建议拍前先看一眼反光再定机位。 |
| 6 | **画幅** | 横竖都可，单张 ≥ 3000×2000 像素（手机默认即可），**不要开美颜/滤镜**。 |

## 三、强烈建议加拍 3 张（用于报告/视频/海报复用）

| # | 文件名 | 构图要点 | 为什么值得拍 |
| - | ------ | -------- | ------------ |
| 5 | `05_工作场景图.jpg` | 板子在多功能房实景，吸顶灯亮起 + 板载 LED 亮，环境占 2/3 | 证明「控制的是**真实**灯」，不是效果图 |
| 6 | `06_证据墙截图.png` | 浏览器打开 `http://192.168.31.251:8099` 全屏，能看到 `LIGHT` / `SPK` 与事件流水 | 唯一能一图证明「端→云→设备→回读」闭环的材料 |
| 7 | `07_语音入口同框.jpg` | 小爱音箱 + 板子同框，可有人手或手机在旁 | 说明语音入口是**家人已在用的设备**，不是新硬件 |

> 本项目**没有 3D 打印外壳，是裸开发板**——不必为此额外拍「外壳」镜头，也不要 P 图加壳。四视图按裸板拍即可；如果想让画面更整洁，可以临时放在一块纯色垫板或亚克力支架上。

### 加拍一张「屏幕状态」特写（新增，很值得）
| # | 文件名 | 构图要点 |
| - | ------ | -------- |
| 8 | `08_屏幕状态特写.jpg` | 近距离正对 LCD，画面里要能同时看到 **屏幕上的 [灯 开] 芯片** 和 **物理 LED 亮起**。拍两张：灯开时一张、灯关时一张（`08a` / `08b`），用来说明「小爱控灯 → 板子屏幕同步」。 |

---

## 四、拍摄顺序建议（省时间）

1. 先拍 **01–04 四视图**（板子静止、灯亮着，一次布光拍完）
2. 拍 **08 屏幕状态特写**（灯开 / 灯关各一张：先拍开，再对小爱说「关灯」后立刻拍关）
3. 打开证据墙截 **06**
4. 最后摆 **05 / 07 场景图**，拍完后**顺手把灯重新打开**，为录视频的关灯场景留好初始状态

---

## 五、拍完自检

- [ ] 四视图齐全，且都是**同一台板子**
- [ ] 每张放大 100% 看：**没有**出现密码 / Token / `.env` / 终端凭据
- [ ] 屏幕那张能看清 **[灯]** 芯片的字，且不是「网络未连接」
- [ ] 至少有一张能看出是**真实环境实拍**（场景图）
- [ ] 文件名规范、无中文乱码、单张 < 10 MB

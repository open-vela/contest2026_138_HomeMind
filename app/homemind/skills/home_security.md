# 家庭安防技能

## 描述
家庭安防技能提供家庭安全监控和报警功能，包括人脸检测、异常行为识别和报警通知。

## 触发条件
- 检测到陌生人脸
- 检测到异常行为（如长时间无人活动）
- 门窗传感器触发
- 温度/湿度异常
- 噪音异常

## 执行动作
1. 拍照记录现场情况
2. 发送通知到小程序
3. 触发声光报警（如果启用）
4. 记录事件日志
5. 通知家庭成员

## 响应策略
- 首次触发：静默记录，发送通知
- 二次触发：发送紧急通知，启动录像
- 三次触发：触发报警，通知所有家庭成员

## 配置参数
`json
{
  "sensitivity": "medium",
  "notification_enabled": true,
  "alarm_enabled": true,
  "recording_enabled": true,
  "notification_channels": ["wechat", "sms"]
}
`

## 使用示例
`
用户：检测到陌生人脸
系统：已拍照记录，发送通知到家庭成员
用户：再次检测到陌生人脸
系统：启动录像，发送紧急通知
用户：第三次检测到陌生人脸
系统：触发报警，通知所有家庭成员
`

## 注意事项
- 隐私模式下，所有数据仅在本地处理
- 敏感时间段（如夜间）可调整检测灵敏度
- 可设置白名单人员，避免误报

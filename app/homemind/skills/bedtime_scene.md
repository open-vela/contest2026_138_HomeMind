# 睡前场景（bedtime）

## 触发
用户说：「我准备睡觉了」「准备睡觉」「晚安」「good night」。

## 行动（家庭侧，白名单）
1. 调用家庭 API `POST /v1/scenes` body: `{"scene":"bedtime","device_id":"esp32s3-eye"}`
2. 或本地直接：`led.off`，并通过家庭网关下发 `mihome.set_power` 关闭吸顶灯
3. 创建待办：「睡前刷牙」「检查门窗与闹钟」（10/15 分钟提醒）
4. 播报：「好的，开始睡前准备。灯我会关上，待办已记下。」

## 边界
- 不发送原始音视频出家庭；仅必要文本可走 MiMo
- 未知动作拒绝执行并记录 reason
- 断网时本地 LED/离线工具仍可用；米家与播报依赖家庭局域网

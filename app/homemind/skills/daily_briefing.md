# 每日简报技能

## 描述
每日简报技能提供每日家庭状态汇总，包括环境数据、设备状态、日程安排和待办事项。

## 简报内容
### 环境数据
- 室内温度和湿度
- 空气质量指数
- 光照强度
- 噪音水平

### 设备状态
- 在线设备数量
- 离线设备列表
- 设备运行时长
- 异常设备告警

### 日程安排
- 今日日程
- 明日日程
- 重要提醒
- 待办事项

### 安全状态
- 安防系统状态
- 最近告警记录
- 异常事件汇总

## 触发条件
- 定时触发：每天早上 8:00
- 手动触发：用户请求
- 事件触发：检测到异常时

## 简报格式
`json
{
  "date": "2026-07-19",
  "environment": {
    "temperature": 25,
    "humidity": 60,
    "air_quality": 50,
    "light": 500,
    "noise": 30
  },
  "devices": {
    "online": 10,
    "offline": 2,
    "alerts": []
  },
  "calendar": [
    {
      "time": "09:00",
      "title": "团队会议",
      "description": "讨论项目进度"
    }
  ],
  "security": {
    "status": "armed",
    "alerts": []
  }
}
`

## 使用示例
`
用户：今日简报
系统：
📅 2026年7月19日 每日简报

🌡️ 环境数据
- 温度：25°C
- 湿度：60%
- 空气质量：优

📱 设备状态
- 在线设备：10台
- 离线设备：2台

📅 今日日程
- 09:00 团队会议
- 14:00 客户拜访

🔒 安全状态
- 安防系统：已启用
- 今日告警：无
`

## 配置参数
`json
{
  "report_time": "08:00",
  "include_environment": true,
  "include_devices": true,
  "include_calendar": true,
  "include_security": true,
  "notification_enabled": true
}
`

## 注意事项
- 简报内容可根据用户偏好定制
- 敏感信息在隐私模式下可能被隐藏
- 可设置简报发送渠道（小程序、微信、短信）
